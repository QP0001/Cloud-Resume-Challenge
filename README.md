# Cloud Resume Challenge - AWS

**🌐 公開URL**：https://d3819481cvuung.cloudfront.net

---

## これは何？

自分の履歴書をAWS上で公開し、**ページを開いた人の数を自動でカウント・表示**する仕組みを作りました。

アクセスすると、画面の下に **「Visitors: ○○」** と表示されます。これはAWS上で動くプログラムがリアルタイムでカウントしています。
