## これは何？

自分の履歴書をAWS上で公開し、ページを開いた人の数を自動でカウント・表示する仕組みを作りました。

アクセスすると、ページの下に 「Visitors: ○○」と表示されます。これはAWS上で動くプログラムがリアルタイムでカウントしています。
